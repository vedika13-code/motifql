The background model sets how chance hits are predicted. "Uniform" treats every letter as equally likely; fitting on a file with Markov order 1 or higher captures neighbour effects such as CpG depletion in real genomes.

      


      

        Language quick reference
        

          
alphabet DNA;DNA, RNA or PROTEIN. Every letter in the program is checked against it.

          
motif m = "TATAWAWR";A named motif. IUPAC codes work: W = A/T, R = A/G, N = any base.

          
[ACG]  [^AG]One letter from a set, or any letter not in it.

          
("A" | "G")Either alternative.

          
"N"{20,40}  *  +  ?Repeat: 20 to 40 times, zero or more, one or more, optional.

          
motif p { @a "N"{5} @b }Build a motif from other named motifs.

          
allow 1 mismatchTolerate one wrong letter.

          
allow 1 editsTolerate one wrong, missing or extra letter.

          
allow 1 mismatch at 1,2,5Errors only at those positions.

          
allow ? editsLet the compiler choose the number of errors.

          
require rate <= 2 per 100kbLimit on chance hits that the chosen errors must meet. Add , divergence 10% to set how far real sites drift.

          
search m in "file.fa";Search one of your sequence files.
